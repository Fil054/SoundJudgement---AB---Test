# SoundJudgement---AB---Test
Frequentist and Bayesian analysis of a public health A/B testing experiment, including data cleaning, statistical inference, Monte Carlo simulation, and sequential Bayesian analysis, implemented in R-studio. 

## Overview

This project analyses data from a public health A/B testing experiment designed to investigate whether exposure to different types of music is associated with differences in participants' perceptions and evaluations.

The analysis combines frequentist and Bayesian statistical methods, with a particular focus on uncertainty quantification and sequential analysis.

## Objectives

The project investigates three main questions:

1. Whether the type of music is associated with differences in the probability of participants believing that children will be hit.

2. Whether the type of music affects participants' ratings of a railway safety video.

3. How Bayesian evidence evolves as observations are collected sequentially.

## Methodology

The analysis includes:

- Data validation and error detection
- Data cleaning and transformation
- Descriptive statistics
- Frequentist hypothesis testing
- Bayesian inference
- Beta-Binomial modelling
- Normal-Normal modelling
- Monte Carlo simulation
- Sequential Bayesian analysis
- Posterior probability estimation
- Data visualisation

## Implementation

The project was developed in R using packages including:

- tidyverse
- ggplot2
- readxl
- patchwork
- scales

The code covers the complete analytical workflow, from data validation and preparation to statistical inference and visualisation.
